# Simples perfeito

Skill global `simplify-ui`. Aplica o briefing:

> I want this to be as perfect as Linear's website or Apple Notes: simple purpose,
> simple architecture, simple design, simple implementation. Cut taglines, helper
> text and secondary labels. If a screen needs them to make sense, fix the layout.
> Every decision should elevate the user experience (UX), developer experience (DX)
> and agent experience (AX) at once, without breaking anything.

## Uso

- `$simplify-ui simplifica a página /planos`
- `Use simplify-ui no menu e no rodapé`
- `Revise este componente com simplify-ui antes de eu aprovar`

## Relação com outras skills

- `layout-audit`: auditoria completa com pesquisa, plano e PDF.
- `simplify`: redução de código sem mudar comportamento.
- `unslop`, `ui-ux-pro-max`, `seo-optimization-suite`: critérios de craft, uso e SEO
  quando a tarefa exigir.

## Limites

Não autoriza commit, push, deploy, mudança de preço, contrato ou URL. Não remove
informação necessária para decidir, preencher formulário, entender erro ou cumprir
obrigação legal.
